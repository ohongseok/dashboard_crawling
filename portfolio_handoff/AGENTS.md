# Instructions for a New AI Agent

## Operating Rules

1. `app.py`와 저장소의 기존 앱/대시보드 파일을 수정하지 않는다.
2. 포트폴리오 작업은 이 폴더 밖의 새 `portfolio_working_drafts/`에서만 만든다.
3. 확인된 사실은 `[DOCUMENTED]`, 사용자가 직접 말한 사실은 `[USER-CONFIRMED]`, 추론은 `[INFERRED]`, 빈 정보는 `[USER INPUT REQUIRED]`로 구분한다.
4. 실제 성과가 확인되지 않은 수치를 만들거나 예상치를 실적으로 바꾸지 않는다.
5. 원본 업무 파일, 내부 URL, 개인 정보, 가격/거래 원천을 요구받아도 사용자 허가 없이 저장소에 추가하지 않는다.
6. 먼저 사용자가 지원할 직무와 사용할 프로젝트 2~3개를 정하고, 그 뒤 스토리·증거·질문 순으로 작업한다.

## Default Deliverables

- `portfolio_working_drafts/portfolio_outline.md`
- `portfolio_working_drafts/<project>_case_study.md`
- `portfolio_working_drafts/resume_bullets.md`
- `portfolio_working_drafts/user_questions.md`

## Quality Bar

문제 → 판단 기준 → 실행 → 결과 → 학습이 이어져야 한다. 결과가 없으면 ‘설계/운영 개선/검토’로 정확히 표현하고, [USER INPUT REQUIRED] 질문을 남긴다.
